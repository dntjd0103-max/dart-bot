# DART 내부자 매수 알림

매일 저녁, 그날 올라온 **임원·주요주주 특정증권등 소유상황보고서**와 **5% 대량보유 보고** 중 보유 주식이 늘어난 건만 골라 보고자·직위·증감수량·지분율까지 정리해 텔레그램으로 알려주는 도구입니다.

> v1: 공시 제목으로 필터링해 링크 목록을 하루 1개 메시지로 전송
> v2(현재): elestock·majorstock API로 상세 내역을 붙이고, 이례적/복수 매수 신호와 CSV 기록 추가

## 왜 만들었나

가격·거래량 기반 기술적 지표는 시장의 모든 참여자가 보는 정보라서, 백테스트에서 잘 맞던 전략도 기간을 바꾸면 쉽게 무너졌습니다.
그래서 **회사를 가장 잘 아는 내부자가 자기 돈으로 주식을 사는 행동**에 주목했습니다.
매도는 세금·생활자금 등 회사 전망과 무관한 이유로도 일어나지만, 매수는 확신 없이는 하기 어렵다고 봤습니다.

다만 모든 매수가 같은 신호는 아니라고 생각해서 두 가지 필터를 넣었습니다.

| 신호 | 기준 | 의미 |
|---|---|---|
| ⚡ 이례적 매수 | 같은 사람이 지난 3년 동안 **매년 같은 달**에 매수한 기록이 없음 | 습관적 매수가 아닌, 특정 시점의 판단일 가능성 |
| 🔁 루틴 매수 | 지난 3년 동안 매년 같은 달에 매수 | 정기 매수, 신호가 약함 |
| 🔥 복수 내부자 매수 | 최근 30일 안에 같은 회사에서 2명 이상 매수 | 여러 내부자가 같은 판단을 했을 가능성 |

알림은 **복수 매수 → 이례적 매수 → 지분율 변화 크기** 순으로 정렬됩니다.

## 동작 방식

```
DART 공시 목록 (오늘, 지분공시 D002, 코스피·코스닥, 정정공시 제외)
  → 회사별 임원·주요주주 소유보고 이력 조회 (elestock API)
  → 오늘 공시 중 보유 주식이 늘어난 건만 추출
  → 이력으로 이례적/루틴, 복수 매수 판단
  → 5% 대량보유 보고(D001)는 majorstock API로 증가 건과 보고 사유를 별도 섹션에 표시
  → 텔레그램 알림 + data/alerts.csv에 기록
  → GitHub Actions가 평일 19:17(한국시간)에 자동 실행
```

## 한계 (알고 쓰기)

- 소유상황보고서의 '증감'에는 장내매수뿐 아니라 무상증자, 주식배당, 신규 선임 등으로 늘어난 경우도 섞일 수 있습니다. 알림의 **공시 원문** 링크에서 취득 사유를 확인하세요.
- 이례적/루틴 기준은 연구(Cohen, Malloy, Pomorski, 2012)를 참고해 단순화한 본인 가설이며, 국내 시장에서의 효과는 data/alerts.csv가 쌓인 뒤 직접 검증할 계획입니다.
